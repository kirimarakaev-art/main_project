# Golang — справочник по языку Go

Учебный веб-проект на Node.js: небольшой справочник по Go с темами из базы данных, сессиями и регистрацией пользователей. Сделан по учебному пособию «Программирование: учебный проект на JavaScript» (Москалева Ю.П., 2024), но на собственную тему.

## Возможности

- Страницы тем («История Go», «Горутины», «Каналы», «Установка и первая программа») по адресам `/topics/:nick`, данные берутся из MongoDB.
- Навигационное меню строится автоматически из базы.
- Регистрация и вход через одну форму: новый пользователь создаётся, у существующего проверяется пароль.
- Пароли не хранятся в базе — только хэш и соль.
- Сессии хранятся в MongoDB, на главной странице есть счётчик посещений за сессию.
- Страницы тем доступны только после входа, гостя перенаправляет на главную.

## Стек

- **Node.js**, **Express 4**
- **MongoDB**, **mongoose**
- **EJS** + **ejs-locals** (общий layout страниц)
- **Bootstrap 5**
- **express-session**, **connect-mongo**, **dotenv**

## Запуск

Нужны Node.js и запущенная MongoDB на `127.0.0.1:27017`.

```bash
npm install
cp .env.example .env
```

В файле `.env` замените значение `SESSION_SECRET` на длинную случайную строку, например результат команды `openssl rand -hex 32`.

Заполните базу темами (достаточно один раз):

```bash
node createDB.js
```

Запустите сервер и откройте http://localhost:3000:

```bash
npm start
```

## Запуск в Docker

Так проект разворачивается на VPS. Нужны только Docker и Docker Compose, Node.js и MongoDB ставить не надо: сайт и база запускаются в двух контейнерах.

```bash
git clone https://github.com/kirimarakaev-art/main_project.git
cd main_project
cp .env.example .env
```

В `.env` впишите свой `SESSION_SECRET` (например, `openssl rand -hex 32`). Затем соберите и запустите контейнеры:

```bash
docker compose up -d --build
```

Один раз заполните базу темами:

```bash
docker compose exec app node createDB.js
```

Сайт откроется на порту 3000: `http://<IP сервера>:3000`. Другой порт можно задать переменной `APP_PORT`, например `APP_PORT=8080 docker compose up -d`.

Полезные команды:

| Команда | Что делает |
|---|---|
| `docker compose ps` | состояние контейнеров |
| `docker compose logs -f app` | логи сайта |
| `git pull && docker compose up -d --build` | обновить сайт до новой версии |
| `docker compose down` | остановить контейнеры (данные базы сохраняются) |

### На одном сервере с другими сайтами

Если на сервере уже работает Caddy (например, из проекта [poker-with-friends](https://github.com/kirimarakaev-art/poker-with-friends)), сайт запускается без открытого порта и получает HTTPS через Caddy:

```bash
docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d --build
```

Файл `docker-compose.prod.yml` убирает публикацию порта 3000 (Docker открывает такие порты в обход файрвола), подключает сайт к общей сети Docker `web` под именем `golang-site` и ограничивает кэш MongoDB 256 МБ. Caddy узнаёт о сайте из файла вида `/opt/caddy-sites/go.caddy`:

```
go.78-17-98-149.sslip.io {
	reverse_proxy golang-site:3000
}
```

Данные MongoDB лежат в томе `mongo-data` и переживают перезапуск и пересборку. Порт базы наружу не открыт, к ней есть доступ только у контейнера с сайтом.

## Структура проекта

```
app.js               настройка приложения: база, сессии, middleware, роутеры
bin/www              запуск HTTP-сервера
routes/              маршруты: главная, вход/выход (index.js), страницы тем (topics.js)
models/              модели mongoose: Topic, User
middlewares/         меню из базы, текущий пользователь, проверка входа
views/               шаблоны EJS, общий layout в views/layout/page.ejs
public/              статика: стили, картинки
data.js, createDB.js данные тем и скрипт заполнения базы
topicStyles.js       иконка и цвет карточки для каждой темы
Dockerfile           сборка образа сайта
docker-compose.yml   сайт и MongoDB в двух контейнерах
```

Файлы `testMongoose.js` и `checkUser.js` — пробные скрипты из глав 7 и 10 пособия, для работы сайта они не нужны.

## Ветки

Каждый пункт пособия сделан в отдельной ветке вида `go_<глава>_<пункт>`, каждая следующая создана от предыдущей:

| Главы | Ветки | Что сделано |
|---|---|---|
| 4 | `go_4_2` … `go_4_4` | маршруты, шаблоны, общий layout |
| 5 | `go_5_1`, `go_5_2` | Bootstrap и навигационное меню |
| 6 | `go_6_1` … `go_6_3` | подключение MongoDB и заполнение базы |
| 7 | `go_7_1` … `go_7_3` | mongoose, схема и модель Topic |
| 8 | `go_8_1` … `go_8_4` | страницы тем из базы |
| 9 | `go_9_1` … `go_9_5` | cookie, сессии, счётчик, меню из базы |
| 10 | `go_10_1` … `go_10_8` | регистрация, вход, выход, закрытые страницы |

Ветка `go_10_8` — проект в том виде, в каком он получается по пособию. Итоговая версия с новым дизайном, светлой и тёмной темой — в ветке `main`.
